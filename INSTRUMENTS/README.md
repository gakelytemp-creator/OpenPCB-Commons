# Instruments

This directory is for tools and methods used to investigate electronic black boxes.

The first concepts include:

- compact two-sided PCB optical/electrical scanner;
- camera + laser height profiling;
- paired precision probes for contact verification;
- passive R/C/L/diode/continuity investigation;
- controlled powered test modes;
- contactless electric-field sensing;
- electrolyte-assisted local scanning concepts;
- microscope-scale investigation;
- external imaging imports such as X-ray or thermal data;
- AISocket interfaces that let an LLM propose the next useful experiment.

There is no single official OpenPCB machine.

Each instrument should document what it can observe, how it was calibrated, what uncertainty it has, and what type of evidence it produces.
