# Contributing

OpenPCB Commons is designed so that contribution does **not** require building a complete scanner or owning an expensive laboratory.

You can contribute:

- one good photograph of a board;
- one component identification;
- one corrected marking;
- one continuity measurement;
- one recovered net;
- one block-diagram hypothesis;
- one schematic fragment;
- one known failure mode;
- one successful repair;
- one second-life use for a salvaged part;
- one instrument design;
- one calibration method;
- one disagreement supported by evidence;
- one historical identification;
- one manufacturer document that may legally be shared;
- one link between two related board families.

## Evidence and inference

Please distinguish, when possible:

- **Observed** — directly visible or measured.
- **Confirmed** — supported by repeatable evidence.
- **Inferred** — a technical conclusion drawn from evidence.
- **Unknown** — unresolved.
- **Disputed** — contributors currently disagree.

A good contribution does not need certainty. It needs honesty about certainty.

## Instruments

If your contribution came from an instrument, please record enough to reproduce or understand the result:

- instrument name/version;
- probe or sensor type;
- measurement mode;
- excitation if any;
- board power state;
- relevant limits/settings;
- calibration information when important.

## Forks are welcome

Different tools and different approaches are part of the project.

If you build a better scanner, probe, microscope attachment, fixture, measurement front end, or software tool, add it under `INSTRUMENTS/` or link to its repository.

We do not want one mandatory machine.

We want many corridors into the black box.

## Community tone

Technical disagreement is welcome.

If you think an interpretation is wrong, show why. Add a measurement, a counterexample, a datasheet, a corrected schematic, or a better explanation.

The archive should become more accurate because disagreement is possible.

## Start small

If you are not sure where to begin:

1. Pick one board.
2. Photograph both sides.
3. Record visible markings.
4. Identify what you can.
5. Mark what remains unknown.
6. Leave the record where someone else can continue.

**Come open one with us.**
