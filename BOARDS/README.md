# Boards

Each investigated board can have its own directory.

During the Noepedia pilot, this directory structure should also act as a portable human-readable export/mirror of a board whose **live structured identity, relations, provenance, and search index** may reside in Noepedia. GitHub files remain useful; Noepedia is intended to make the same board searchable relationally across many boards and evidence trails.

A future board record may contain:

- `README.md` — identity, context, current knowledge status;
- `images/` — top, bottom, details, markings;
- `geometry/` — board outline, holes, connector positions;
- `components/` — identified and unknown parts;
- `measurements/` — raw and processed measurements;
- `nets/` — known connectivity and confidence;
- `schematics/` — fragments and reconstructed schematics;
- `blocks/` — functional block diagrams;
- `repairs/` — failures, diagnoses, repair outcomes;
- `provenance/` — which tool/method produced which evidence.

A board does not need to be completely understood before it belongs here.

Partial knowledge is useful knowledge.
