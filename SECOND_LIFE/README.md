# Second Life

This directory records how useful parts survive the product they came from.

Examples:

- motors and encoders;
- sensors;
- displays;
- printheads;
- pumps;
- fans;
- power supplies;
- actuators;
- cameras;
- mechanical assemblies;
- controller boards;
- connectors and fixtures.

For each reusable part, useful information may include:

- source product;
- part markings;
- electrical interface;
- mechanical dimensions;
- mounting pattern;
- connector pinout;
- communication protocol;
- drive requirements;
- known substitutions;
- example reuse projects.

The long-term goal is not to force standardization.

It is to make compatibility visible enough that useful patterns can spread naturally.
